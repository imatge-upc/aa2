# Machine Learning II (AA2) — Lecture Notebooks

Short PyTorch notebooks accompanying the theory lectures of **Machine Learning II (AA2)**
in the [Bachelor's Degree in Data Science and Engineering](https://dse.upc.edu/en) at
the **Universitat Politècnica de Catalunya (UPC)**.

They provide executable examples of the concepts introduced in class and complement the lecture slides.
Notebooks for the laboratory sessions are provided separately.
